# Adaptive researcher

Research beliefs select inspections; they have zero truth authority. Evaluator,
canonical payment/monetary semantics, authority, robots and verified geography
requirements remain unchanged.

The working model derives a bounded vocabulary ledger from owned source headings
and research-only search titles. Queries combine a current deficit with newly
observed wording and provenance; their identities include that wording/question.
Japanese/Korean/Arabic/other source terms remain original strings. Language is a
research clue, never market evidence. Search snippets are retained as research-only
records and cannot become admitted observations.

Selection uses ordinal information-value factors, source relationship, novelty,
family yield, duplicates, current deficits and channel cost. Raw structured/shell
information gain is distinct from established truth. Empty search conversion can
expose an uninspected reviewed root. No guessed pricing routes are injected.

Inert JSON and hydration catalogs produce exact source spans, JSON pointer paths
and bounded parent objects. Public endpoint references become reviewed, robots-
compliant HTTP GET candidates; no script execution, endpoint guessing or GraphQL
mutation/POST capability is added. Keys/numbers only select material. Typed charge,
benefit, effective cost, payment and commitment interpretation still needs the
existing source-bound evidence adapter. Unsupported interpretation stays unknown.

Presentation combines existing structural regions with complete structured
objects. Selected state is retained even when alternative enumeration fills up.
An oversized selected qualifier invalidates the price region it qualifies; it
cannot vanish. An unrelated alternatives limit does not veto all offer units.
Incomplete document/control scans still fail closed. Weak, invalidation-aware
material caching returns copies so callers cannot mutate source material.

Advisory and semantic failure circuits are independent. Advice reserves one shared
model call for understanding. Intact relevant monetary observations can receive
one local INSPECT after a declared 429 cooldown, within action/model limits; no
provider request is repeated. No timer or retry-until-success loop exists. Native
candidates and retained bodies survive failures.

Source-state alternatives may share a Decodo session for eight acquisitions or
15 minutes, maximum 64 cached journeys. Independent acquisitions get fresh session
bindings. Each acquisition retains its own unchanged country pre/post integrity
bracket. These are exit sessions, not authenticated cookie/browser journeys.
Restoring a process does not promise reuse of a remote exit; a fresh session must
still satisfy the same geography receipt contract.

Legacy stop reasons remain compatible. The additional `researchStop` receipt
separates objective resolved, capacity exhausted, understanding/tool unavailable,
channel capability exhausted, policy/authority blocked, search strategy exhausted
and scoped research exhaustion. It never asserts universal web exhaustion or
annual-only from absence.

Limits: 64 vocabulary/clue/search records; 12 source-derived query proposals per
view; source vocabulary scans at most 32 latest sources, 262144 characters each;
512 working resources, 256 families/hypotheses/state variants; existing bounded
history/decision/provenance; 32 JSON islands, 262144 bytes/island, 4096 nodes/island,
depth 32, pointers 2048 characters, 256 retained regions/endpoints, 4096 bytes per
region; existing four semantic units and acquisition/network/byte ceilings.

Separate design stage: browser rendering, cookie journeys, general JavaScript
execution and read-only GraphQL POST contract are not implemented here. Sources
requiring these channels report a capability limitation; HTTP/client-state support
must not be reported as browser acquisition. Model-assisted translation/query
reasoning is not necessary for source-derived multilingual wording, but unseen
language semantics can still require successful understanding.
