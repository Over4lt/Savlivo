# Source-bound offer eligibility

This correction preserves extraction observations and existing source/market,
commercial, quarantine and confidence policies. It does not supply missing trial
or renewal relationships.

The existing commercial context guard rejects a temporal phase clause as a plan
identity. For generic HEADING_CONTAINER claims it independently checks the source
using existing bounded component recognition, a single-title product article, or
an exact named structured product/price description. A heading's proximity and
extractor strong flag alone are insufficient. Other existing named-card, typed
product, table, subscription-declaration and offer-presentation paths remain.

Zero observations are retained, but Savlivo excludes zero from recurring
provider-price eligibility globally. If trial/intro context occurs within its own monetary owner and the
existing closed-renewal structure does not establish its role, the zero remains
an observation with ZERO_COMMERCIAL_PHASE_UNRESOLVED. This does not attach another
card's context or manufacture a renewal amount.

The field verifier rederives source evidence, blocks identity/ownership and phase
fields as applicable, and reports V2_FIELD_VERIFICATION_V3. The qualified price
adjudicator also consumes these independently rederived vetoes, even if a stored
candidate's old commercial flags claim success. The new reasons are not tolerated
by MEDIUM qualification. No general V2_VERIFIED requirement is added to HIGH/MEDIUM.

Derived evidence and adjudicated observations carry
SOURCE_BOUND_OFFER_ELIGIBILITY_V2. Missing/incompatible derived identity cannot
be used by the current verifier. Identity verification rejects incompatible
candidate-decision versions; it cannot relabel V2 decisions as V3 successes.
These version strings are compatibility markers, not authentication. Historical
artifacts are not rewritten or automatically reinterpreted. No recovery or
artifact-pinning policy is introduced; future recovery must validate both
compatibility and authenticated artifacts independently.

Retained summaries now also apply the shared recurring-price eligibility policy,
including current quarantine and invalidation. Cached summaries are revalidated
when consumed; historical artifacts are not migrated. See
`../live/retained-pricing.md` for the summary trust boundary.
